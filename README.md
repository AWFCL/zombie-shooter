# 打僵尸 · Zombie Shooter

一个用原生 Canvas + Web Audio 写的俯视角僵尸生存射击游戏。**单文件、零依赖、离线可玩**，不需要任何框架或插件。

在线试玩：<https://awfcl.github.io/zombie-shooter/>

## 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | `W A S D` 或方向键 |
| 瞄准 | 鼠标 |
| 射击 | 按住鼠标左键 |
| 换弹 | `R`（打空自动换） |
| 暂停 | 空格 或 `Esc` |
| 静音 | `M` |
| 重开 | 死后按 `R` 或点一下鼠标 |

## 内容

- **三种僵尸**：行尸（慢、皮厚）、疾行者（快、脆）、壮尸（大块头、有血条），各有不同的体型和走路动作
- **Boss**：每 4 波出现一个（屠夫 / 暴君 / 母体循环），顶部专属血条，残血会暴走
- **升级**：每击倒 2 个 Boss，全场冻结、三选一强化（伤害 / 射速 / 弹夹 / 换弹 / 移速 / 生命 / 穿透）
- **难度递增**：每波血量 +10%、伤害 +6%、速度 +2.2%，出怪更多更快
- **声音**：全部用 Web Audio 现场合成，没有音频素材文件；僵尸嘶鸣带左右声道和距离衰减
- **场景**：永久血迹和尸体、暗角、颗粒、枪口光照、镜头抖动

## 本地运行

双击 `index.html` 即可，**不需要服务器、不需要联网**。

> 注意：浏览器不会自动重读本地文件，改完代码要关掉标签页重新打开（或 `Ctrl+F5`）。

## 技术说明

- 逻辑分辨率 960×600，按设备像素比渲染，窗口自适应缩放
- 地面、血迹层、噪点、暗角都是离屏 canvas 预渲染
- 音频用 `AudioContext` 合成，首次点击/按键后解锁（浏览器自动播放策略）
- 最高分存在 `localStorage`
